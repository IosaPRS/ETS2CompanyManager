# ETS2 Company Manager

[English](README.md) · **Русский** · [Deutsch](README.de.md)

Программа для Windows, которая показывает и помогает вести твою компанию в Euro Truck Simulator 2. Она читает
сейв и собирает в одном окне всех водителей, траки, прицепы, гаражи и рейсы, а ещё умеет безопасно чинить,
заправлять, менять номера, улучшать гаражи и прокачивать навыки водителей прямо в сейве.

## Что умеет

- **Водители**: город, гараж, опыт, навыки, трак, прицеп, статус, текущий маршрут, прибыль и €/день.
  Статусы в цветах игры: в рейсе, порожняком, на стоянке, простаивает, поломка, без трака.
- **Траки и прицепы**: пробег, топливо, износ по деталям, постоянный износ (с 30% водитель отказывается ехать), статус.
- **Гаражи**: тип, места, водители, прицепы, доход в день и продуктивность.
- **Рейсы**: кто что везёт и куда, расстояние, время в пути, цена парома.
- **Вкладка «Навыки»**: для каждого водителя выбираешь, что прокачать, как в игре (дальние перевозки, ценные,
  хрупкие грузы, срочная доставка, экономичное вождение и шесть классов ADR).
- **Правка сейва**: ремонт (всех или выбранного), заправка, смена номеров, апгрейд малого гаража до большого, навыки.
- Тёмная и светлая тема, интерфейс на русском, английском, немецком и французском, сортировка и фильтр в каждой таблице.
- Следит за сейвом: когда игра записывает новый автосейв, таблицы обновляются сами.

## Установка

**Windows .exe**: скачай `ETS2CompanyManager.exe` и запусти. Он сам находит свежий сейв в
`Documents\Euro Truck Simulator 2\profiles\...\save\`; если не нашёл, выбери *Файл → Открыть сейв* и укажи `game.sii`.

**Из исходников** (Python 3.10+):

```
pip install PySide6 cryptography pillow
python ets2_gui.py
```

`cryptography` нужна для чтения зашифрованных сейвов, `pillow` только для `tools/convert_assets.py`.
Консольная сводка тоже есть: `python ets2_manager.py "<путь к game.sii>"`.

## Как безопасно править сейв

- Сначала закрой игру: пока она открыта, она перезапишет изменения, и программа откажется писать.
- Перед каждой правкой копия сейва кладётся в папку `ets2cm_backups` рядом с `game.sii`.
  *Файл → Восстановить сейв из резервной копии* возвращает её.
- Программа меняет только нужные поля, затем сверяет результат с оригиналом и ничего не пишет,
  если отличается что-то лишнее.
- Сначала попробуй на копии слота сохранения.

## Языки и темы

*Язык / Language* и *Тема* находятся в строке меню. Переводы лежат обычными JSON-файлами в `locales/`.
Чтобы добавить язык, скопируй `en.json`, переведи значения, укажи `"_name"` и положи файл в папку: он появится в меню.
Подробности в `locales/README.md`.

## Сборка .exe

`build_exe.bat` собирает через PyInstaller (сначала `pip install pyinstaller`). В auto-py-to-exe добавь папки
`assets` → `assets`, `locales` → `locales`, файл `requirements/driver_names.json` → `requirements`,
скрытый импорт `cryptography`, иконка `assets/ui/app_icon.ico`.

## Ограничения

- Предел навыков на вкладке «Навыки» задаётся вручную (максимум 36): таблицы опыта по уровням в программе пока нет.
- Классы ADR сопоставлены битам по возрастанию (1, 2, 3, 4, 6, 8); проверь одно изменение в игре, прежде чем на него полагаться.
- Статус «порожняком» определяется по рейсу с нулём единиц груза, это предположение.
- Продуктивность гаража считается по прибыли за 7 дней и цене гаража
  (150 000 € малый, 300 000 € большой); совпадала со значениями из игры.
- Цену апгрейда гаража вводишь сам: впиши ту, что показывает игра.
- Имена водителей берутся из таблицы `requirements/driver_names.json` (в сейве их нет); любого водителя можно переименовать.
