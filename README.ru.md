# ETS2 Company Manager

[English](README.md) · **Русский** · [Deutsch](README.de.md)

Программа для Windows, которая показывает и помогает вести твою компанию в Euro Truck Simulator 2. Она читает
сейв и собирает в одном окне всех водителей, траки, прицепы, гаражи и рейсы, а ещё умеет безопасно чинить,
заправлять, менять номера, улучшать гаражи, прокачивать водителей и заполнять пустые гаражи новыми водителями, траками и прицепами прямо в сейве.

## Что умеет

- **Водители**: город, гараж, опыт, навыки, трак, прицеп, статус, текущий маршрут, прибыль и €/день.
  Статусы в цветах игры: в рейсе, порожняком, на стоянке, простаивает, поломка, без трака.
- **Траки и прицепы**: пробег, топливо, износ, статус.
- **Гаражи**: тип, места, водители, прицепы, доход в день и продуктивность.
- **Рейсы**: кто что везёт и куда, расстояние, время в пути, цена парома.
- **Вкладка «Навыки»**: для каждого водителя выбираешь, что прокачать, как в игре (дальние перевозки, ценные,
  хрупкие грузы, срочная доставка, экономичное вождение и шесть классов ADR).
- **Правка сейва**: ремонт (всех или выбранного), заправка, смена номеров, апгрейд малого гаража до большого, навыки,
  баланс компании и уровень игрока.
- **Заполнить гаражи** (вкладка *Гаражи*): найм водителей на свободные места из игрового списка соискателей
  (лучшие, случайные или самые дешёвые), им можно отдать свои свободные траки или копии своих траков и добавить прицепы. Можно нанять и без траков.
- **Строка предупреждений** над вкладками: водители с проблемой, изношенные траки, водители без трака, траки без водителя, пустые места в гаражах.
  Клик по пункту показывает только эти строки.
- Следит за сейвом: когда игра записывает новый автосейв, таблицы обновляются сами.

## Установка

**Windows .exe**: скачай `ETS2CompanyManager.exe` и запусти. Он сам находит свежий сейв в
`Documents\Euro Truck Simulator 2\profiles\...\save\`; если не нашёл, выбери *Файл → Открыть сейв* и укажи `game.sii`.

Сейвы American Truck Simulator тоже открываются, но названия траков, логотипы и имена водителей пока сделаны для ETS2. Скоро добавлю поддержку траков и водителей ATS.

**Из исходников** (Python 3.10+):

```
pip install PySide6 cryptography
python ets2_gui.py
```

`cryptography` нужна для чтения зашифрованных сейвов.
Консольная сводка тоже есть: `python ets2_manager.py "<путь к game.sii>"`.

## Как безопасно править сейв

- По умолчанию правка идёт в новый слот сохранения *<имя сейва> Edited*: исходный сейв остаётся как был, а игру можно
  не закрывать, достаточно загрузить новый слот. Следующие правки этого слота пишутся в него же.
  Чтобы править сам выбранный сейв, выключи *Настройки → Сохранять правки в копию сейва*; тогда игру нужно закрыть.
- Перед каждой правкой копия сейва кладётся в папку `ets2cm_backups` рядом с `game.sii`.
  *Файл → Отменить последнюю правку* (Ctrl+Z) или *Файл → Восстановить сейв из резервной копии* возвращает её. Хранятся последние 20 копий.

## Языки и темы

Язык выбирается в *Настройки → Язык* (при первом запуске берётся язык системы, иначе английский), *Тема* находится в строке меню. Переводы лежат обычными JSON-файлами в `locales/`.
Чтобы добавить язык, скопируй `en.json`, переведи значения, укажи `"_name"` и положи файл в папку: он появится в меню.
Подробности в `locales/README.md`.
