# Notice

ETS2 Company Manager is an unofficial fan-made tool and is not affiliated with or endorsed by SCS Software.
Euro Truck Simulator 2 and its game assets (truck brand logos, driver portraits, UI icons in `assets/`) are the property of SCS Software s.r.o.
They are included only so the program looks like the game. If the rights holder asks for their removal, the files in `assets/` will be removed.
The program reads save files only and writes to them only on explicit user action: into a new copy of the save slot (the original stays untouched) or, if that is turned off, after making a backup.
